Research & Projects

Happiness Prediction from Survey Data — Feed-Forward Neural Network
Built a cleaning/imputation pipeline for 3,669 survey responses in pandas/NumPy, then implemented a feed-forward neural network from scratch (forward pass, backpropagation, no ML framework). Compared four optimizers across four architectures; best model reached 99.17% test accuracy.
View on GitHub →
Minimum-Cost Power Transmission Network — Custom QP Solver
Proved convexity/coercivity of a 16-variable quadratic program for routing minimum-loss transmission lines, then wrote a general-purpose QP solver from scratch (LP, unconstrained, KKT, and active-set branches). Validated on a 33-constraint instance, confirming theoretical predictions.
View on GitHub →
Multi-Scale Method for Ill-Conditioned Linear Systems
Implemented and benchmarked Jacobi, Gauss-Seidel, and a column-scaling multi-scale method; proved a bound on the rescaled system's condition number. Reduced a condition number of 10⁴ to 2.4, letting Gauss-Seidel converge to 10⁻¹² relative error in 6 iterations where the unscaled system stagnated.
